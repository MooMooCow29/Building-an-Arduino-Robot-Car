# Schematics

This folder is reserved for schematic files (e.g. Fritzing `.fzz`,
KiCad `.kicad_sch`, or exported PDFs/SVGs).

## Tools

- [Fritzing](https://fritzing.org) — beginner-friendly breadboard/schematic editor
- [KiCad](https://www.kicad.org) — professional open-source EDA suite
- [EasyEDA](https://easyeda.com) — browser-based, free

## Recommended Schematic Contents

When adding a schematic, include:

1. Arduino Uno with all used pins labelled
2. L298N module with motor connections
3. HC-SR04 module
4. Battery and power distribution
5. Any decoupling capacitors
